# Day 13 Notes - Python Libraries Used in AI

# NumPy

Purpose

- Numerical Computing
- Arrays
- Matrix Operations
- Linear Algebra

Import

```python
import numpy as np
```

---

# Pandas

Purpose

- Load CSV
- Clean Data
- Filter Data
- Analyze Data

Import

```python
import pandas as pd
```

---

# Matplotlib

Purpose

- Data Visualization

Import

```python
import matplotlib.pyplot as plt
```

Used for

- Line Chart
- Bar Chart
- Pie Chart
- Histogram
- Scatter Plot

---

# Scikit-learn

Purpose

Machine Learning Algorithms

Examples

- Linear Regression
- Logistic Regression
- Decision Tree
- Random Forest
- K-Means

Import

```python
from sklearn.linear_model import LinearRegression
```

# Typical AI Workflow

1. Load data using Pandas.
2. Perform numerical operations using NumPy.
3. Visualize data using Matplotlib.
4. Train Machine Learning models using Scikit-learn.
5. Use TensorFlow or PyTorch for Deep Learning if required.
