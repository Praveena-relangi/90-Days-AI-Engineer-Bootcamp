This project analyzes the SuperStore sales dataset using Python, Pandas, and Matplotlib.

1. Data Exploration
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Visualization
5. Business Insights

# Project Workflow

## Phase 1 – Data Exploration

Performed:

- Dataset overview
- Column analysis
- Data type inspection
- Statistical summary
- Missing value identification

Outcome:

Successfully understood the dataset structure before analysis.

---

## Phase 2 – Data Cleaning

Performed:

- Missing value analysis
- Duplicate record validation
- Date conversion
- Postal Code investigation

Outcome:

- No duplicate records found.
- Date columns converted to datetime.
- Missing Postal Code values retained because no reliable reference existed within the dataset.

- Which region performs best?
- Which customer segment contributes the most?
- Which states generate the highest revenue?
- Which cities generate the highest revenue?
- Which products generate the highest sales?
